# Проверки на хардуерните проекти

## Интеграция · 29 октомври 2026 г.

Трите предоставени Wokwi архива са прегледани като изходен код и диаграми. Публичното копие на Pico контролера запазва логиката на архива, но премахва вградения validator ключ и включва локалната настройка през Serial Monitor. Адресът се задава с `URL …`.

| Проверка | Резултат |
| --- | --- |
| Backend API и интеграционни тестове | 56 преминали |
| Pico: keypad, състояния, LED/servo времена и HTTP договор | 13 преминали CPython теста |
| Скрипт за постоянен публичен адрес | 6 преминали теста |
| Wokwi lint: трите диаграми | 0 грешки, 0 предупреждения |
| Mega AVR compile + link | Успешни: 35 translation units, 27 362 B flash, 2 242 B RAM |
| ESP32 source | Съвпада с вече компилирания `kiosk-9` от 28 октомври |

Wokwi CLI 0.29.1 отбелязва някои типове платки, дисплея и RFID четеца като недокументирани компоненти. Това са информационни съобщения, а не пропуснати свързвания.

## Възпроизводими проверки

От корена на хранилището:

```sh
python hardware/scripts/check_projects.py
python -m unittest discover -s hardware/wokwi/ticket-validator/tests -v
python -m unittest discover -s software/scripts/tests -v
```

GitHub Actions добавя чиста компилация на вендинг firmware за `arduino:avr:mega` с AVR core 1.8.6. Версиите на библиотеките са зададени в workflow. Диаграмите могат да се проверят и с `wokwi-cli lint <папка> --warnings-as-errors`.

Локалната Mega проверка използва директно AVR-GCC 7.3.0 от Arduino toolchain, AVR core 1.8.6 и същите версии на библиотеките като CI. Извършени са sketch preprocessing, компилация на приложението/библиотеките/core и свързване до ELF. Самият Arduino CLI не може да открие платформата в ограничената Windows среда; стандартният CLI път остава зададен в GitHub Actions.

## Граници на проверката

Предишна изолирана Wokwi проба на Pico изходите отчита два зелени импулса през първата секунда, отваряне на 90° и затваряне след 5 секунди; това не е пълна мрежова покупка и валидиране. Публичният API е проверяван отделно от компютър. Пълният HTTPS обмен от Pico през публичния Wokwi gateway остава непотвърден след наблюдавани TLS EOF грешки.

За ESP32 са проверени компилация, старт, кирилица, избор на до 8 места, сумиране и прелистване на билетите; пълна покупка през текущия публичен тунел не е изпълнена като част от тази интеграция. Вендинг схемата и логиката са прегледани; механично дозиране и точност на количествата не са измервани.

Физически платки, механика, реални плащания и денонощна мрежова надеждност не са изпитвани. Проверка на диаграма и host тестове не заменят тези изпитвания.
