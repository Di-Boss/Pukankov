# Arduino Mega: четири серва и четири стъпкови мотора

Схема за проверка на моторите от предоставения проект. Запазени са Arduino Mega, breadboard, четирите серва с техните цветове и четирите NEMA 17. Добавен е отделен A4988 за всеки стъпков мотор. Breadboard и Mega са преместени под драйверите за четимост.

## Отваряне в Wokwi

1. Създай или отвори Arduino Mega проект.
2. Замени съдържанието на `diagram.json` с файла от тази папка.
3. Замени `sketch.ino` с приложения тестов код.
4. Добави `Servo` 1.3.0 през Library Manager или копирай `libraries.txt`.
5. Стартирай симулацията. Serial Monitor използва 115200 baud.

Сервата последователно заемат 0°, 180° и 90°. После всеки стъпков мотор прави 200 стъпки в едната и 200 в обратната посока. Цикълът се повтаря. Това е тест на свързването; няма логика за дозиране, калибриране, крайни изключватели или комуникация със сайта.

## Пинове

| Компонент          | Сигнал              | Arduino Mega    |
| ------------------ | ------------------- | --------------- |
| servo1, зелен      | PWM                 | D2              |
| servo2, червен     | PWM                 | D3              |
| servo3, оранжев    | PWM                 | D4              |
| servo4, лилав      | PWM                 | D5              |
| stepper1 / driver1 | STEP / DIR / ENABLE | D22 / D23 / D30 |
| stepper2 / driver2 | STEP / DIR / ENABLE | D24 / D25 / D31 |
| stepper3 / driver3 | STEP / DIR / ENABLE | D26 / D27 / D32 |
| stepper4 / driver4 | STEP / DIR / ENABLE | D28 / D29 / D33 |

Номерацията следва ID на частите. Отляво надясно моторите във входния проект са `stepper2`, `stepper1`, `stepper4`, `stepper3`.

Пинове D0/D1 за Serial и D20/D21 за I²C са свободни. Управлението на сервата е чрез библиотеката Servo; не използва `analogWrite()`.

## Захранване и A4988

За симулацията `mega:5V` и `mega:GND.1` захранват горните breadboard шини. Всички използвани контакти са в първата секция на тези шини.

При всеки A4988:

- `VDD`, `SLEEP` и `RESET` са на общата логическа шина 5 V, всеки на отделен breadboard контакт.
- И двата GND пина са свързани с общата маса.
- `MS1`, `MS2`, `MS3` са на GND за full-step режим: 200 стъпки/оборот.
- `ENABLE` е отделен управляващ пин, активен при LOW.
- `1B → B-`, `1A → B+`, `2A → A+`, `2B → A-` свързват двете намотки.

**VMOT е оставен несвързан само за Wokwi**, защото симулаторът не моделира това захранване. Това не е схема за физическо захранване на моторите. При реален монтаж A4988 изисква отделно моторно захранване, съобразено с драйвера и моторите, настройка на тока и подходящ кондензатор до VMOT. Четирите серва също се захранват от подходящ отделен 5 V източник, с обща маса с Mega; не от 5 V пина на платката.

Официални справки: [A4988](https://docs.wokwi.com/parts/wokwi-a4988), [стъпков мотор](https://docs.wokwi.com/parts/wokwi-stepper-motor), [серво](https://docs.wokwi.com/parts/wokwi-servo).

## Проверка

Схемата премина официалната проверка `wokwi-cli lint --warnings-as-errors` с Wokwi CLI 0.29.1: **No issues found**. Проверени са 14 компонента и 74 връзки. Изпълнение на firmware във Wokwi и движение на физически мотори не са проверени; lint потвърждава валидността на частите и имената на пиновете.

Локална компилация е опитана с Arduino CLI 1.5.1, AVR core 1.8.8 и Servo 1.3.0. Компилаторът не се стартира заради Windows грешка `Illegal System DLL Relocation`; няма получен резултат от компилация. За изпълнение използвай компилацията в Wokwi. Тестовият sketch не е проверен върху физическа платка.
