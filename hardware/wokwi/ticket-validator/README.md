# ESP32 валидатор с keypad

**Статус: спецификация; firmware и Wokwi схема предстоят.**

## Предназначение

Зрителят въвежда шестцифрения код от сайта или билетния автомат. Устройството изпраща код и ID на прожекцията към общия API. Само положителният сървърен отговор разрешава достъп.

## Планирани компоненти

ESP32, матрична keypad клавиатура, дисплей, зелен и червен индикатор. Реле/серво може да представя входната бариера в симулацията. Конкретните GPIO и модели се документират при добавяне на схемата.

## Поведение на интерфейса

| Вход / събитие                      | Действие                                                |
| ----------------------------------- | ------------------------------------------------------- |
| Цифри `0`–`9`                       | Добавяне до максимум 6 цифри                            |
| `*`                                 | Изчистване на въведения код                             |
| `#`                                 | Изпращане само при точно 6 цифри                        |
| Чакащ отговор                       | Блокиране на повторно изпращане и индикация за проверка |
| HTTP 200 и `valid:true`             | Зелен индикатор; еднократно разрешаване                 |
| `valid:false`, HTTP грешка, timeout | Червен индикатор; входът остава затворен                |

При изгубен отговор след успешна проверка повторната заявка получава `already_used`. Това е безопасният резултат; операторът разглежда случая отделно, вместо устройството да отключва повторно.

## Заявка

```http
POST /api/validator/validate
Authorization: Bearer DEVICE_KEY
Content-Type: application/json

{"ticket_code":"482617","showtime_id":123}
```

ID на прожекцията се избира от актуалната програма. Ключът е с роля `validator` и може да е ограничен до зала. Никога не поставяй реалния ключ в публикуван sketch. Виж [договора за устройства](../../../software/docs/devices.md).

## Приемане

Изпълни сценариите H-01 до H-08 от [матрицата](../../docs/validation-scenarios.md). При двама валидатори за един код точно едно устройство трябва да получи разрешение. Запиши действителните резултати след реална симулация.
