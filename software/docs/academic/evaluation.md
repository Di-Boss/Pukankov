# Методика за оценяване

## Проверявани твърдения

1. Конкурентните канали използват една наличност и не продават едно място два пъти.
2. Повторна заявка за checkout връща същата поръчка.
3. Валидирането е еднократно, включително при две едновременни заявки.
4. Грешна прожекция и неуспешно плащане не дават право на вход.
5. Промяната на билетния формат запазва предишни поръчки и употреба.

Това са проверими свойства на реализацията. Те не доказват производителност при произволно натоварване или надеждност на бъдещ хардуер.

## Метод

Backend тестовете създават изолирана SQLite база и изпълняват реалните маршрути и услуги. Конкурентните сценарии синхронизират отделни заявки, след което проверяват резултата в базата. Миграционният тест изгражда старата схема, добавя стар билет и прилага новата миграция.

Playwright проверява потребителските потоци в Chromium: търсене, места, checkout, отрицателен резултат, билети, любими, администрация и адаптивност. Тестът на платежния payload проверява, че картовите данни не се изпращат до backend. Не се използва реална банка.

В ограничената предходна среда браузърът е свързан с реалния ASGI стек през тестов мост без TCP. В GitHub Actions и при обичайното `npm run test:e2e` се стартират отделни локални HTTP сървъри. Различните транспортни условия се посочват в протокола.

## Критерий за приемане

Всички задължителни функционални сценарии трябва да преминат, build да завърши успешно, а Alembic да не открива разминаване с моделите. Негативните случаи се считат за успешни тестове, когато достъпът е отказан и данните остават съгласувани.

## Ограничения на валидността

- SQLite и PostgreSQL използват различни стратегии за заключване. Локалният резултат не заменя PostgreSQL integration тестове.
- Успешен HTTP отговор не доказва физическо отключване; GPIO тестът е отделен експеримент.
- Проверки на шест ширини не са пълен одит за достъпност.
- Кратки функционални тестове не определят SLA, throughput или средно време за отговор.
- Шестцифреният формат има ограничено пространство; необходима е миграция преди изчерпване.
