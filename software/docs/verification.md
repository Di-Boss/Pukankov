# Резултати от проверките

## Текуща интеграция · 29 октомври 2026 г.

Production build на актуалния код е изпълнен успешно с Vite `--configLoader native` след TypeScript проверка. Обичайният config loader е блокиран от достъпа на esbuild до родителските Windows директории в работната среда; конфигурацията на проекта не е променяна заради това.

**15 от 15 Playwright сценария преминават** и при текущата интеграция върху production build, с отделна временна SQLite база и реални тестови HTTP сървъри. За Windows средата е използван Vite preview с временна конфигурация, насочена само към тестовия backend на порт 8001; локалният сайт и неговата база не са тестова среда.

**56 backend теста преминават** върху изолирани временни бази. Те покриват потребители и роли, CSRF, места и задържания, конкурентни заявки, учебни плащания, идемпотентен checkout, билети и еднократно валидиране. Успешно минават и 6 теста на настройката за постоянен публичен адрес.

API за терминала приема `payment_success` от устройството. Не приема UID, клиентска цена или баланс по RFID карта. Проверени са общата наличност за сайт и терминал, покупка на до 8 места, отказано плащане, повторени/конкурентни заявки, изтичане на задържане и ограничения по роля.

## Повторение

От `software/`, с инсталирани зависимости:

```sh
npm run build
python -m pytest backend/tests -q
npm run test:e2e
```

GitHub Actions изпълнява тези проверки от чист checkout. Локални бази, ключове и генерирани диагностични файлове не се версионират.

## Ограничения

Текущите локални тестове връщат предупреждения от Starlette/anyio и pytest за съвместимост и недостъпен стар кеш; няма паднал backend тест. PostgreSQL/Docker runtime, реален платежен доставчик, SMTP, физически хардуер, натоварване и пълен одит на сигурността/достъпността не са изпитвани.
