Backend покрива: 15 авторски филма, скриване на стар каталог без загуба на покупки, профили, роли, CSRF, rate limiting, любими, собственост, holds и изтичане, конкурентност, успешна/отказана учебна транзакция, промокодове/цени, идемпотентност, кодове, retry при колизия, обща наличност за сайт и kiosk, валидатори, миграция, администрация, export и deletion request.

Браузърните сценарии покриват: търсене и детайли, каталог/пагинация, покупка на desktop/mobile, шестцифрени билети, отказ и нова покупка, липса на картови данни в HTTP payload, любими след reload, search modal с Escape, администрация и записи/одит, публични маршрути и responsive ширини. Подбрани екрани са включени в `docs/media/`; генерираната при тестове папка `screenshots/` не се версионира.

Проверката на структурата `software/` / `hardware/` започва с чисто инсталиране на npm зависимостите от lockfile. Production build и 15-те Playwright сценария преминават през реални TCP/HTTP сървъри, с изолирана SQLite база и случайна администраторска парола. Тестовите данни и диагностиката са в `.test-artifacts/`.

При стартиране на backend тестовете от `software/` миграционният тест първоначално откри зависимост от текущата папка. Subprocess вече задава изрично `software/backend/`, а целевият миграционен тест е повторен успешно. Останалите 36 теста преминаха в общото изпълнение. Предходната проверка на работното копие също включва 37 преминали теста. GitHub Actions изпълнява целия набор от чист checkout.

За ограничени среди е запазен опционален ASGI мост с `PUKANKOV_INMEMORY_API=1`. Той изпълнява реалния backend без мрежов транспорт, но не доказва достъпност на TCP порт. Този режим не е използван за последната браузърна проверка на новата структура.

Локалният сайт е потвърден като работещ след стартиране от Windows терминал. Wokwi/ESP32 и Raspberry Pi хардуер не са стартирани; проверен е общият API и Python клиентът е синтактично проверен.

Единственото pytest предупреждение е deprecation notice за per-request cookies в теста на отзована сесия (Starlette/httpx); няма паднал тест. Playwright показва само предупреждение за конфликтни NO_COLOR/FORCE_COLOR настройки на средата.

Не са изпълнявани външен security audit, пълен WCAG audit, PostgreSQL load tests или реални платежни интеграции. Виж README за ограниченията и необходимите стъпки преди търговско внедряване.
